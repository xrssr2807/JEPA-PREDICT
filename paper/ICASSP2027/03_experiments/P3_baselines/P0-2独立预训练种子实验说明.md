# P0-2 PhysioV2 vs Multimodal MAE 独立预训练种子

## 为什么要做

P0 下游多种子实验只改变了微调随机性。PhysioV2 的 CHD AUC 在三个下游种子中都高于 MAE，但尚不能排除 seed42 预训练权重的偶然性。

本实验将预训练优化种子设为 42、3407、2026，并将下游种子固定为 42，从而隔离“预训练随机性”。

## 严格固定条件

- 预训练数据划分种子：42
- 下游患者级划分 SHA256：`e3d458a8e88c75bf0b144be9bca5c7ecc87173f75425fe5cf0e2d77822cb9716`
- 下游优化种子：42
- 双通道、Patient-MIL on、Multi-scale on、Shared-Private head off
- 测试集全程封存

## 运行

```bash
bash scripts/run_icassp_evidence_pipeline.sh
```

默认只运行 `p0_independent`，即当前最高优先级的证据缺口。脚本支持断点续训、完成检测、记录哈希和中间权重清理。

## 自动汇总

最终输出：

- `independent_pretrain_runs.csv`
- `independent_pretrain_paired.csv`
- `independent_pretrain_aggregate.csv`
- `summary.json`

论文判定以 CHD AUC 为主，Macro AUC 为重要次要结果。若 PhysioV2 在至少 2/3 个独立预训练种子上优于 MAE，且平均差值为正，才继续强化“CHD 任务优势”的论文叙事。

## 后续实验顺序

1. 根据已运行的非对称双向权重实验选择 alpha，再用独立预训练种子确认。
2. 对最新 PhysioV2 完成动态延迟、静态延迟和零延迟的配对实验，回答“动态”是否必要。
3. 对单调性、dustbin、反事实排序和双端内容代价做组成消融。
4. 使用时间平移恢复、正向/反向/随机配对和跨采样率评估完成机制与鲁棒性闭环。
5. 所有模型选择结束后，仅一次解封测试集，报告 ROC、PRC、校准、bootstrap CI 和配对显著性。

`run_icassp_evidence_pipeline.sh` 也预留了 `direction_pilot`、`constraint_completion`、`time_shift` 和 `cross_device` 阶段。这些阶段不默认自动运行，因为它们应根据前一阶段结果固定参数，避免无目的地消耗 GPU 和引入验证集选择偏差。
