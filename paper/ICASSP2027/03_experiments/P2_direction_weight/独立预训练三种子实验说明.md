# 双向任务权重独立预训练三种子实验

## 目的

正式比较非对称目标 `alpha=0.5` 与对称目标 `alpha=1.0`，排除单次预训练权重偶然性。

方向损失保持为：

`L_dir = (L_ECG→PPG + alpha * L_PPG→ECG) / (1 + alpha)`

## 严格控制

- 预训练种子：`42 / 3407 / 2026`。
- 每个种子先生成一个共同 Shared-Private 父模型，再从同一父模型分叉训练两个 alpha。
- 下游随机种子固定为 `42`，避免把下游随机性混入预训练比较。
- 八标签患者级互斥划分固定，SHA256 为 `e3d458...cb9716`。
- 双通道、Patient-MIL、多尺度和 SP-off 下游头保持一致。
- 测试集保持封存，只使用验证集完成方法选择。

## 预设决策规则

采用 `alpha=0.5` 需要同时满足：

1. CHD AUC 在至少两个预训练种子上高于 `alpha=1.0`，且平均配对差值为正。
2. Macro AUC 平均配对差值不低于 `-0.002`。

否则保留更简单的对称目标 `alpha=1.0`。
