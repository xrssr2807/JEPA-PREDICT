# 时间平移实验方案与运行说明

## 运行条件

- Phase 2 最优权重：
  `outputs_phase2_shared_private_seed42/jepa_best.pt`
- 冻结划分：
  `splits/multidisease_taskaware_downstream.json`
- 数据：
  `/root/ppgchd/ppgchd/data_updated`
- 数据角色：`val`
- 默认采样：最多 512 个片段，每位患者最多 2 个片段
- 注入位移：`-320, -160, -80, 0, 80, 160, 320 ms`
- 统计单位：患者
- Bootstrap：2000 次

## 远程执行

```bash
cd /root/autodl-tmp/JEPA-PREDICT-priority1
conda activate JEPA

nohup bash scripts/run_transport_time_shift.sh \
  > transport_time_shift_sequence.log 2>&1 &

echo $! > transport_time_shift_sequence.pid
tail -f transport_time_shift_sequence.log
```

默认依次执行 `teacher_tokens` 和 `waveform` 两组。

结果自动归档到：


## 快速质检

先只跑 token 域、128 个片段：

```bash
DOMAINS="teacher_tokens" \
MAX_SEGMENTS=128 \
BOOTSTRAP_ITERATIONS=200 \
PAPER_DIR=outputs_transport_time_shift_smoke \
bash scripts/run_transport_time_shift.sh
```

## 主要成功标准

1. 非零位移的未补偿损失整体高于零位移。
2. 已知位移补偿带来正的损失改善，且 95% CI 尽量不跨 0。
3. 恢复位移与注入位移呈正相关，患者级恢复斜率接近 1。
4. `teacher_tokens` 结果应强于或至少比 `waveform` 更干净、更单调。

若波形域较弱但 token 域显著，应解释为输入编码器对零填充边界和全局上下文
较敏感，而不是直接否定 Transport 的时序几何。
