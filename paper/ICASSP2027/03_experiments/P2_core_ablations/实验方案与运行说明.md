# P2 核心消融实验方案与运行说明

## 实验目标

P2 用最小受控矩阵回答四个论文问题：

1. 跨模态 JEPA 预训练是否优于随机初始化。
2. Phase 0、Phase 1、Phase 2 的增量是否成立。
3. 动态延迟 Transport 是否带来独立收益。
4. Patient-level MIL 和多尺度下游头是否带来独立收益。

主要指标为验证集冠心病 AUC，次要指标为验证集宏平均 AUC 和宏平均 F1。
本阶段测试集保持封存。

## 固定条件

- 数据：八标签患者级互斥划分。
- 划分：`splits/multidisease_taskaware_downstream.json`。
- 输入：ECG+PPG 双通道。
- 下游 Shared-Private 头：关闭。
- 阈值、早停和模型选择：仅使用验证集。
- 初筛随机种子：42。
- 复现随机种子：3407、2026。

## 第一步：运行无需重新预训练的六组初筛

在远程服务器执行：

```bash
cd /root/autodl-tmp/JEPA-PREDICT-priority1
conda activate JEPA

mkdir -p logs

# 先核验三个阶段的权重。当前服务器若缺少 Phase 1，必须先从原实验
# 服务器复制，不能用 Phase 0 或 Phase 2 权重代替。
for f in \
  /root/autodl-tmp/JEPA-PREDICT/outputs/jepa_best.pt \
  /root/autodl-tmp/JEPA-PREDICT/outputs_phase1_perf/jepa_best.pt \
  /root/autodl-tmp/JEPA-PREDICT/outputs_phase2_shared_private_seed42/jepa_best.pt
do
  test -s "$f" || echo "缺少权重: $f"
done

nohup env \
  SEEDS="42" \
  EXPERIMENTS="random_init phase0 phase1 phase2 mil_off multiscale_off" \
  PHASE0_CKPT="/root/autodl-tmp/JEPA-PREDICT/outputs/jepa_best.pt" \
  PHASE1_CKPT="/root/autodl-tmp/JEPA-PREDICT/outputs_phase1_perf/jepa_best.pt" \
  PHASE2_CKPT="/root/autodl-tmp/JEPA-PREDICT/outputs_phase2_shared_private_seed42/jepa_best.pt" \
  SPLIT="splits/multidisease_taskaware_downstream.json" \
  bash scripts/run_p2_core_ablations.sh \
  > logs/p2_core_seed42.log 2>&1 &

echo $! | tee logs/p2_core_seed42.pid
tail -f logs/p2_core_seed42.log
```

## 第二步：重新训练无 Transport 的 Phase 2

Transport-off 不能用 Phase 1 冒充，必须以相同预算重新训练 Phase 2：

```bash
cd /root/autodl-tmp/JEPA-PREDICT-priority1
conda activate JEPA

nohup env \
  SEED=42 \
  BASE_OUTPUT=outputs_phase2_no_transport_seed42 \
  SP_OUTPUT=outputs_phase2_shared_private_no_transport_seed42 \
  bash scripts/run_p2_transport_ablation_pretrain.sh \
  > logs/p2_transport_off_pretrain_seed42.log 2>&1 &

echo $! | tee logs/p2_transport_off_pretrain_seed42.pid
tail -f logs/p2_transport_off_pretrain_seed42.log
```

完成后运行下游 Transport 消融：

```bash
env \
  SEEDS="42" \
  EXPERIMENTS="phase2 transport_off" \
  PHASE2_CKPT="/root/autodl-tmp/JEPA-PREDICT/outputs_phase2_shared_private_seed42/jepa_best.pt" \
  PHASE2_NO_TRANSPORT_CKPT="outputs_phase2_shared_private_no_transport_seed42/jepa_best.pt" \
  bash scripts/run_p2_core_ablations.sh
```

## 第三步：选择需要三随机种子复现的比较

seed 42 完成后，优先保留满足以下任一条件的比较：

- 冠心病 AUC 的绝对差值不少于 0.005。
- 宏平均 AUC 的绝对差值不少于 0.005。
- 虽然效应较小，但该组件属于论文核心方法且方向与假设一致。

选中的比较再运行：

```bash
SEEDS="42 3407 2026" \
EXPERIMENTS="phase2 需要复现的实验ID" \
bash scripts/run_p2_core_ablations.sh
```
