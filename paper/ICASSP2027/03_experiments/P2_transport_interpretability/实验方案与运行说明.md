# 生理约束动态因果 Transport：可解释性验证方案

状态：代码已完成，等待远程验证集运行。测试集继续封存。

## 研究问题

本实验不再只问“Transport 是否提高 AUC”，而是分别验证：

1. **生理约束**：模型学习的 ECG→PPG 时延是否与波形中可观测的 PAT 一致；
2. **动态性**：逐片段、逐 token 的动态时延是否优于固定 250 ms 时延；
3. **方向一致性**：正向 ECG→未来 PPG 是否优于零时延、负时延和时间反转；
4. **配对特异性**：正确 ECG/PPG 配对是否优于跨患者打乱 PPG；
5. **疾病关联**：Transport 时延统计是否与冠心病状态存在关联。

## 生理定义

- ECG R 峰表示心室电激动时间锚点；
- PPG 足点表示外周脉搏波到达时间；
- 二者时间差称为 **pulse arrival time（PAT）代理值**；
- ECG→PPG PAT 包含心脏射血前期，因此不能写成纯粹 PTT；
- 当前模型在 token 层只允许正向延迟，并加入时延先验、单调性、平滑性和未匹配质量约束。

配置中的请求范围为 80–800 ms。由于编码器总步长为 16、采样率为 100 Hz，
一个 token 对应 160 ms，因此实际离散支撑为 160、320、480、640、800 ms。
论文中必须报告这一实际分辨率，不能只写 80–800 ms。

## 因果表述边界

本实验验证的是 **causal temporal consistency / causal-direction inductive bias**：
ECG 电活动先于 PPG 外周血容量响应，模型只允许沿该方向搬运 token。

它不能仅凭观察性 ECG/PPG 数据证明哲学或干预意义上的因果发现。论文中避免使用
“discovers causality”，建议写成：

> a physiology-constrained causal-direction transport operator

## 八组可解释性对照

| 条件 | 含义 | 预期 |
|---|---|---|
| dynamic causal | 模型学习的正时延 Transport | 最低对齐距离 |
| segment static delay | 每段保留平均延迟分布、移除 token 变化 | 差于动态 Transport |
| token-shuffled delay | 保留延迟边缘分布、打乱 token 位置 | 差于动态 Transport |
| cross-patient delay policy | 正确波形配对、交换患者延迟策略 | 差于动态 Transport |
| fixed prior | 所有片段固定为 250 ms 附近 | 差于动态 Transport |
| zero delay | ECG 与同位置 PPG token 对齐 | 差于动态 Transport |
| negative delay | PPG 被放到 ECG 之前 | 明显变差 |
| reversed PPG | PPG 时间轴反转 | 明显变差 |
| shuffled pair | 跨患者错配 ECG/PPG | 明显变差 |

评价单位为患者。正式验证覆盖冻结验证集全部 1,155 位患者，每位患者按固定
随机种子最多抽取 2 个片段。先对同一患者的片段求平均，再执行患者级 bootstrap
95% CI。该规则避免片段较多的患者被过度加权，同时保留患者内片段变化。

`MAX_SEGMENTS=512`。

## 论文判定标准

只有同时满足以下条件，才将“生理约束动态因果 Transport”作为标题级创新：

1. 模型时延与波形 PAT 存在非平凡相关且误差可接受；
2. dynamic causal 显著优于 segment-static、token-shuffled、
   cross-patient delay policy、fixed prior 与 zero delay；
3. negative delay、reversed PPG、shuffled pair 显著更差；
4. 单调违反率接近 0，匹配质量没有退化到 dustbin；
5. Transport-on 相比 Transport-off 的冠心病 AUC 优势在三个随机种子上稳定。

若仅第 5 条成立，应将论文表述收缩为“physiology-inspired temporal alignment”，
而不是强调可解释的动态因果时延。
