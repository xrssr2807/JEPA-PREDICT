# 跨设备采样率鲁棒性实验

## 研究问题

同一患者信号在 100、50、25 Hz 设备上采集时，模型性能是否稳定；多采样率训练是否能降低低采样率下的性能退化。

## 方法边界

- 使用抗混叠 polyphase 滤波模拟设备降采样，再恢复到统一的 100 Hz 模型时间网格。
- 保持信号物理时长不变，不能用“直接拉伸到固定点数”代替采样率处理。
- 该组件命名为 `PhysicalTimeBridge`，目前是采样率标准化与增强方法，不宣称已经学习出真实 PAT/PTT。
- PAT 的常用定义是 ECG R 峰到外周 PPG 足点/上升沿的到达时间，包含 PEP 与血管传播时间；不是“P 波到 T 波时间”。

## 受控实验

1. Native 训练：不做多采样率增强。
2. Multi-rate 训练：训练时以 0.75 概率从 25/50/100 Hz 中模拟一个设备频率。
3. 两个模型分别固定评估 100/50/25 Hz。
4. 固定患者级八标签划分、随机种子、模型结构和优化器。
5. 只使用验证集，测试集保持封存。

运行：

```bash
bash scripts/run_cross_device_robustness.sh
```

主要结果：`clinical_metrics.csv`、`focus_paired_delong.csv`、冠心病 ROC/PR/校准图。
