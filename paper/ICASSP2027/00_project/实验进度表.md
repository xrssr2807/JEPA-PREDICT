# ICASSP 2027 实验进度表

最后更新：2026-07-27

## 工作规则

1. 除非发现可复现的实现错误，否则不再随意修改主模型架构。
2. 所有论文实验使用固定的八标签、患者级互斥数据划分。
3. 模型和阈值只能根据验证集选择。
4. 所有方法、消融和选择规则固定前，测试集保持封存。
5. 每组实验记录代码提交、划分 SHA256、权重 SHA256、随机种子、配置和输出路径。
6. 每组实验结束后先收集和审核结果，再开始下一组。

## 结果归档检查表

每组实验完成后需要收集：

- 汇总 CSV 和逐次运行 CSV。
- 受控消融实验的配对差值 CSV。
- 控制台日志或下游训练日志。
- 实验清单或冻结清单。
- 数据划分审计结果。
- 最优权重路径和哈希。
- 统计检验阶段所需的患者级预测。

每次结果审核必须记录：

- 完成了哪些实验。
- 是否通过数据泄漏和测试集封存检查。
- 主要和次要指标。
- 均值、标准差和 95% 置信区间。
- 受控对比及配对差值。
- 结果解释和论文结论。
- 下一步具体行动。

## 当前证据

- 三个随机种子中，双通道均优于 PPG 单通道和 ECG 单通道。
- 双通道 SP-off 的冠心病 AUC 为 `0.7991 ± 0.0020`。
- 双通道 SP-on 的冠心病 AUC 为 `0.8001 ± 0.0036`。
- Shared-Private 对 ECG 存在正向趋势，但三随机种子配对 95% 置信区间均包含零。
- Shared-Private 下游头作为次要消融，不作为论文主要提升来源。
- 当前工作主配置为 `SP-off + ECG+PPG`，因为结构更简单且结果更稳定。
- 旧标签体系、旧划分或提前使用测试集产生的历史结果不得混入 ICASSP 主表。
