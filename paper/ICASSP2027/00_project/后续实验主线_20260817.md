# ICASSP 2027 后续实验主线（2026-08-17）

## 论文主张

主张限定为：PhysioV2 为 ECG-PPG 跨模态预训练引入生理有向、动态时序归纳偏置，并在冠心病识别上提供特异性收益。

不主张：

- 所有疾病和所有综合指标全面优于 Multimodal MAE；
- Transport 延迟等同于 PAT/PTT；
- 单个随机种子或开发集差值具有统计显著性；
- 已查看的 132 人前瞻队列属于封存外部验证。

## 阶段 1：双向任务权重选型

比较 `alpha=0.5` 与 `alpha=1.0`，预训练种子固定为 `42/3407/2026`，下游种子固定为 `42`。每个种子先训练共同父模型，再从同一父模型分叉，减少非目标差异。

采用 `alpha=0.5` 必须同时满足：

1. 三个种子中至少两个 CHD AUC 高于 `alpha=1.0`；
2. CHD AUC 平均配对差值为正；
3. Macro AUC 平均差值不低于 `-0.002`。

否则保留更简单的 `alpha=1.0`。

## 阶段 2：PhysioV2 与 Multimodal MAE 独立预训练比较

阶段 1 选出的 PhysioV2 权重直接进入比较。MAE 从头训练 `42/3407/2026` 三个预训练种子，下游随机种子固定为 `42`。

固定条件：

- 相同预训练数据与数据划分种子；
- 相同编码器规模；
- PhysioV2 最终阶段与 MAE 的有效 batch 均为 `384`；
- 相同八标签患者级互斥划分；
- 相同下游头、MIL、多尺度、训练轮数和模型选择规则；
- 只比较验证集，测试集不构建、不读取、不评估。

主要终点为 CHD AUROC；Macro AUROC 为共同判据，同时报告 Macro F1 和患者级预测。

## 严格测试集封存

`--seal_test` 现在执行严格 validation-only 协议：

- 仅解析清单中的 `train/val`；
- 不实例化 Test Dataset；
- 不创建 Test DataLoader；
- 不输出测试指标；
- 日志必须包含：

```text
[Protocol] strict_validation_only=true test_dataset_constructed=false
DEVELOPMENT COMPLETE (TEST SET SEALED)
```

两条正式批处理脚本只有同时发现上述标记、验证集患者预测和最佳权重，才会把运行判为完成。旧的伪封存结果不会被自动复用。

## 一键远程运行

代码同步到远程服务器后，在项目根目录运行：

```bash
cd /root/autodl-tmp/JEPA-PREDICT
conda activate JEPA

mkdir -p logs
nohup bash scripts/run_icassp_model_selection.sh \
  > logs/icassp_model_selection.log 2>&1 &

echo $! > logs/icassp_model_selection.pid
tail -f logs/icassp_model_selection.log
```

该脚本自动完成：

1. `alpha=0.5/1.0` 独立预训练三种子；
2. 按预注册规则选择最终 alpha；
3. PhysioV2 与 Multimodal MAE 独立预训练三种子比较；
4. 汇总并归档验证集结果；
5. 在解封测试集之前停止。

## 后续闸门

完成上述两阶段后，先人工审查：运行完整性、数据划分 SHA256、患者预测、均值与标准差、配对差值和结论边界。只有最终模型、最强基线、阈值和统计方案全部冻结后，才单独编写并授权一次性测试集评估脚本。

25 Hz、年龄/性别和新的前瞻队列放在补充实验，不阻塞 ICASSP 主表证据链。
